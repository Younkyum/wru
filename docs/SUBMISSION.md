# WRU — 좌표 없이 가족 일을 나누는 Muse 협상 레이어

Meta Global AI Developer Hackathon (2026-10-26 ~ 11-04) 제출 설명서

## 문제

가족끼리 "누가 애 데리러 가?"를 정하려면 지금 서로 어디 있는지 알아야 합니다. 그래서 많은 가족이 위치 공유 앱을 켭니다. 그러면 가족 모두의 정확한 좌표와 이동 경로가 늘 기록되고, 앱 · 서버 · 로그 어딘가에 쌓입니다. 정작 필요한 건 "누가 시간 안에 갈 수 있나"라는 답 하나인데도요.

## 해법

WRU는 좌표를 아무도 보지 않게 하면서 역할을 정합니다.

- **WhereCtx**(사용자의 기존 위치 컨텍스트 서버)는 각 사람의 거친 상태만 줍니다: `home` / `near_home` / `in_transit`, 도착까지 남은 분(ETA). 좌표나 상세 위치를 요청하면 거절하고, 집 반경 안이면 `home_zone_refused`로 거절합니다.
- **Muse Spark** 에이전트가 가족 한 사람당 하나씩 붙습니다. 각 에이전트는 **자기** WhereCtx만 읽습니다. 다른 가족의 상태는 모르고, 서로 아는 건 협상 메시지뿐입니다.
- **WRU**는 에이전트 사이의 협상을 중계합니다. 태스크 인박스 → 라운드별 offer / counter / commit / refuse → assignment → 사람 승인 1회 → 사람별 통지(자기 역할만).

## 프로토콜

| 메시지 | 필드 | 의미 |
| --- | --- | --- |
| offer | from, subtask_id, fit(high/medium/low), reason | 이 일을 할 수 있다 |
| counter | from, subtask_id, alternative, fit, reason | 더 맞는 사람이 있으니 다른 일을 하겠다 |
| commit | from, subtask_id | 확정 |
| refuse | from, subtask_id, reason_code | 못 한다 (busy_in_transit, deadline_unreachable 등 템플릿만) |

- 에이전트는 자기 상태 · ETA · 마감까지 남은 시간으로 subtask마다 가능 여부와 적합도를 정합니다.
- 엔진이 commit을 판정합니다. 지난 라운드부터 이어진 자기 claim이 더 높은 적합도의 claim에 밀리지 않을 때만 확정하고, 용량 제약(한 사람 한 일)을 지킵니다. 최대 라운드가 지나면 남은 일은 미배정입니다.
- 결과는 상태에서 나옵니다. 17:30에는 아빠 = 픽업, 형 = 우유이고, 17:52에는 아무도 마감을 맞출 수 없어 미배정입니다.
- 실제 Meta Model API(OpenAI 호환)는 JSON 구조화 출력을 받습니다. 출력이 스키마 검증이나 위치 검사를 통과하지 못하면 같은 입력의 템플릿 판단으로 대체합니다.

## 프라이버시 게이트

1. WhereCtx는 상세 위치를 거절합니다.
2. 실제 Muse 출력은 스키마와 위치 패턴을 검사합니다.
3. **자유 문장 차단**: 에이전트가 쓴 문장은 내보내지 않고, 이유는 항상 상태 템플릿으로 다시 씁니다. ETA는 "10분 이내" 같은 구간으로만 나갑니다.
4. 위치 단서가 든 태스크 라벨은 인박스가 거절합니다.

## 누수 수치

협상 로그만 적대자에게 주고, 가족의 집과 학교가 서울 25개 구 중 어디인지 맞히게 했습니다. 시드 50개 시나리오마다 집 · 학교 · 경로가 다릅니다.

| 조건 | 집 적중 | 학교 적중 |
| --- | --- | --- |
| 게이트 off (동네 이름 · 거리 · 정확한 ETA 그대로) | **98%** | **72%** |
| 게이트 on, 에이전트가 위치를 알고 말하려 할 때 | 6% | 0% |
| 게이트 on (WRU 기본) | **6%** | **0%** |
| 우연 수준 (1/25) | 4% | 4% |

품질 게이트 테스트는 API 응답, 이벤트 로그, UI 렌더, 샘플, 리포트 전체를 검사합니다. 좌표 키 · 소수점 좌표, 도로명, 학교 고유명, 지명이 나온 건수는 0입니다. 테스트 103개가 통과합니다.

## 한계

- 누수 수치는 mock 적대자 기준입니다. 이 적대자는 로그 문장의 단서로 구를 추정하는 휴리스틱입니다. 게이트 off 때의 말투와 휴리스틱을 같은 팀이 만들었으므로, off 수치는 "이런 말이 새면 이 정도로 좁혀진다"는 예시입니다. API 키가 있으면 `npm run leak`이 협상 에이전트와 적대자 모두 Muse로 다시 잽니다.
- 제출 시점에는 Meta Model API 키가 없어서 결정론적 mock Muse로 시연합니다. 실제 클라이언트 경로는 가짜 fetch로 테스트했습니다. 모델 id `muse-spark-1.3`은 가정값입니다.
- WhereCtx는 시뮬레이터 구현만 붙어 있습니다. 실제 WhereCtx MCP는 같은 어댑터 인터페이스 뒤에 붙일 수 있게 분리해 두었습니다.
- 가족 화면(맵)은 Presence 계약대로 정확한 ETA를 보여 줍니다. 협상 로그에는 구간만 나갑니다.
- 태스크 라벨은 사용자가 쓴 자유 문장이라 단어 목록 밖의 상호명까지 다 막지는 못합니다. "봉사활동"처럼 '동'으로 끝나는 말이 걸리는 오탐도 있습니다.
- 실제 가족 온보딩, 푸시 앱, 계정은 범위 밖입니다.
